# Wattar Chair

## التشغيل
```bash
# الخادم
cd backEnd
cp .env.example .env        # ثم املأ القيم
npm run gen-secret          # انسخ الناتج إلى JWT_SECRET في .env
npm install && npm run dev  # (npm run seed لإضافة بيانات تجريبية)

# الواجهة
cd frontEnd
cp .env.example .env
npm install && npm run dev
```

## ملاحظات مهمة
- **لا ترفع ملف `.env` إلى GitHub** (مُضاف إلى `.gitignore`). `JWT_SECRET` إلزامي في الإنتاج.
- غيّر `ADMIN_PASSWORD` في `backEnd/.env` إلى كلمة مرور قوية وفريدة (8 أحرف على الأقل) قبل أول تشغيل؛ ملف `.env.example` نموذج فقط.
- يُنشأ حساب المدير عند أول تشغيل فقط. إذا كان الحساب موجودًا في قاعدة البيانات، فتغيير `ADMIN_PASSWORD` لا يغيّر كلمة مروره. إن لم تُضبط كلمة مرور صالحة عند إنشاء الحساب، تُولَّد كلمة عشوائية وتُطبع مرة واحدة في سجل الخادم.
- **البريد (SMTP):** عند ضبط `SMTP_HOST` تُفعَّل رسائل تأكيد البريد واستعادة كلمة المرور وإشعارات المدير والعملاء،
  ويصبح تأكيد البريد شرطًا لإرسال الطلبات والتعليقات والتقييمات.
  بدونه: تُطبع الروابط في سجل الخادم ويُعتبر البريد مؤكدًا تلقائيًا (مناسب للتطوير).
- الخريطة: ضع رابط تضمين Google في لوحة التحكم > إعدادات الموقع، أو اتركه فارغًا لاستخدام العنوان.
- خلف Nginx/Cloudflare اضبط `TRUST_PROXY=1`.

## الواجهات الجديدة
`/orders` طلباتي · `/gallery` المعرض · `/forgot-password` · `/reset-password` · `/verify-email`

## إدارة أصناف المنتجات
من لوحة التحكم > المنتجات، أضف الأصناف الرئيسية ثم أصنافًا فرعية اختيارية تحت كل صنف. عند إضافة أو تعديل منتج اختر الصنف الرئيسي والصنف الفرعي، وتظهر الأصناف تلقائيًا كمرشحات في المتجر والصفحة الرئيسية. لا يمكن حذف صنف مرتبط بمنتج أو صنف رئيسي ما زالت تحته أصناف فرعية.

## الدولة والعملة
رمز الدولة (963) والعملة (USD) والتاريخ في مكان واحد لكل جانب: `backEnd/.env` (COUNTRY_CODE, CURRENCY_*) و`frontEnd/src/config/locale.js`. يجب أن تتطابق القيم.

## إخفاء الأسعار
لوحة التحكم > إعدادات الموقع > "عرض أسعار المنتجات لجميع الزوار". عند إيقافه يُخفي الخادم الأسعار من الـ API أيضًا (المدير يراها دائمًا).
